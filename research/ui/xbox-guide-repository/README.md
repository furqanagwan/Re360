# The Guide's separate-repository period

From 2026-10-06 to 2026-11-11 the Guide and the XUI runtime were their own repository
(`furqanagwan/xbox`), pinned here as a submodule. Its history is now part of this one and its
sources live in `src/xbox`. These are that repository's records, kept as they were:

- [extraction.md](extraction.md): how the sources left ReXGlue, and the issues transferred
- `provenance.json`, `source-history.txt`: the source commits they came from
- `issue-transfer.json`: which ReXGlue issues moved to the Guide repository
